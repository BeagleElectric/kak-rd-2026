How this board works — read once

Saving is automatic

Click Edit on a unit, change what you need, click Save. That's it. It's stored straight away and it will be there next time you open the page. There is no save button for the board as a whole and nothing else you need to do.

It saves to this browser, on this computer

That's the one thing to understand. The board isn't stored on a server — it lives in the browser you're using right now. So:

  • Open it on your phone and you'll see the original list, not your updates
  • Switch browsers and you'll see the original list
  • Clear your browsing data and your changes are gone
  • Greg doesn't see your changes — he'd see the original list too

Use one computer and one browser for this. If you always work in the same place, it just works and you never think about it.

Export once a week — this is your backup

Click Export. It downloads a small file. Send that to Greg with your Friday report.

That's the only backup that exists. If your computer dies or the browser gets cleared, that file is how the board gets rebuilt — and Greg has a copy of where everything stood.

Import — only when you need it

Use Import to load an export file. You'd only do this if you're on a new computer, or you've lost your data and want to restore from the last export.

Import replaces what's on the board, so only do it when you're sure the file is newer than what you're looking at.

Keep the payment dates current

When you do payment matching on Tuesday and Friday, update Last payment received and Next payment due as you go. The board turns the next payment date red when it's overdue, so if you keep those current the board shows at a glance who's behind — and your Friday screenshot tells Greg everything he needs without you writing it out.
